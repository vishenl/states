Mindvalley Program Page Structure

A new page architecture optimized for both conversions AND Answer Engine Optimization (AEO). This structure ensures maximum visibility in AI answer engines while maintaining high conversion rates.

Current Page vs. New Structure

Aspect Current Ultramind Page New Optimized Structure
Schema Markup Basic OG tags only Full Course, FAQPage, Person, Review schema
FAQ Section 10 generic questions, no schema 30+ search-intent questions with FAQPage schema
Content Structure Marketing-first, brand-centric Value-first, search-intent matched
Headlines Emotional/aspirational Keyword-rich + emotional (dual purpose)
Teacher Section Bio at bottom of page Person schema + early credibility signals
Social Proof Testimonials scattered Review schema + aggregate rating

1

Hero Section (Above the Fold)

Purpose: Capture attention, establish relevance, and provide immediate clarity on what the program delivers.

Required Elements:

  • H1
    Primary Headline (H1)
    Format: "[Program Name]: [Primary Benefit/Outcome]"
    Example: "The Silva Ultramind System: Master Your Mind's Altered States to Manifest Your Goals"
  • P
    Subheadline
    Answer the question: "What will I get from this?" in one sentence.
    Example: "A 28-day program to access Alpha and Theta brain states at will for enhanced intuition, creativity, and problem-solving."
  • IMG
    Hero Image/Video
    Show the teacher or program in action. Include alt text describing the content.
  • BTN
    Primary CTA Button
    Clear action: "Start Your Journey" or "Join Now - $399/year"
  • DIV
    Quick Stats Bar
    3-4 key metrics: Duration, Students Enrolled, Rating, Languages
AEO Optimization: The H1 should contain the primary keyword (program name) + a benefit phrase that matches how people search. AI engines pull H1s as authoritative answers to "What is [Program Name]?" queries.
Conversion Optimization: Hero must answer "Is this for me?" within 3 seconds. Use the stats bar to build immediate credibility (social proof through numbers).
2

Quick Value Proposition (The "What You Get" Section)

Purpose: Immediately communicate the core transformation in scannable format. This section is CRITICAL for AEO because AI engines look for structured, clear value statements.

Required Elements:

  • H2
    Section Headline
    Format: "What You'll Master in [Program Name]" or "Transform Your [Area] in [Timeframe]"
  • UL
    3-5 Core Outcomes (Bullet Points)
    Each bullet = one clear, measurable outcome. Start with action verbs.
    Example:
    - Access Alpha brain states in under 60 seconds using the Centering Exercise
    - Develop intuitive problem-solving abilities through guided visualization
    - Learn healing techniques backed by 60+ years of research
  • DIV
    Quick Feature Cards (Optional)
    Visual cards showing: Duration, Format, Difficulty Level, Prerequisites
AEO Optimization: These bullet points get pulled by AI for "What do you learn in [Program Name]?" queries. Use semantic HTML (ul/li) and front-load each bullet with the key benefit.

Schema Markup for This Section

Wrap this section in itemscope itemtype="https://schema.org/Course" with itemprop="teaches" for each outcome.

3

Problem/Solution Bridge

Purpose: Create emotional resonance by naming the problem the visitor faces, then positioning the program as the solution.

Required Elements:

  • H2
    Problem-Agitation Headline
    Format: "If you're struggling with [Problem], you're not alone..." or "For those seeking [Outcome]..."
  • P
    Problem Description (2-3 paragraphs)
    Name 3-5 specific pain points the visitor experiences. Use "you" language.
  • H3
    Solution Introduction
    Bridge from problem to solution: "The answer lies in..."
  • P
    Methodology Explanation
    Explain the core methodology in plain language. What makes this approach different?
Conversion Optimization: This section builds desire through problem awareness. The visitor should think "Yes, that's exactly my situation!" before seeing the solution.
AEO Optimization: This content answers "How does [Program Name] work?" and "What problem does [Program Name] solve?" - common AI query patterns.
4

What You'll Learn (Curriculum)

Purpose: Show the complete learning journey. This builds confidence that the program is comprehensive and structured.

Required Elements:

  • H2
    Section Headline
    "The Complete [Program Name] Curriculum" or "Your [X]-Day Transformation Journey"
  • DIV
    Module/Week Breakdown
    Expandable accordion for each module with:
    - Module Title
    - Module Description (1-2 sentences)
    - Key Topics Covered (bullet list)
    - Duration/Number of Lessons
  • DIV
    Daily/Lesson Schedule (Optional)
    For Quests: Show the day-by-day breakdown
  • DIV
    Bonus Content
    List any additional resources, tools, or bonus programs included
AEO Optimization: This section answers "What's included in [Program Name]?" and "How long is [Program Name]?" - high-intent purchase research queries.
<!-- Curriculum Schema Markup --> <div itemscope itemtype="https://schema.org/Course"> <h2 itemprop="name">The Silva Ultramind System Curriculum</h2> <div itemprop="hasCourseInstance" itemscope itemtype="https://schema.org/CourseInstance"> <meta itemprop="courseMode" content="online"> <meta itemprop="duration" content="P28D"> </div> <div itemprop="syllabusSections"> <!-- Module content here --> </div> </div>
5

Teacher/Expert Credibility

Purpose: Build trust through the teacher's credentials, experience, and authority. This is CRITICAL for both conversions and AEO.

Required Elements:

  • H2
    Section Headline
    "Meet Your Teacher: [Name]" or "Learn From [Name], [Key Credential]"
  • IMG
    Professional Photo
    High-quality headshot or action shot. Include Person schema.
  • P
    Bio Summary (2-3 paragraphs)
    Focus on: Expertise, credentials, notable achievements, why they're qualified to teach this.
  • UL
    Credential List
    Bullet points of key credentials: degrees, certifications, books, media appearances, client results.
  • DIV
    "As Seen In" Logos
    Media logos where teacher has been featured (NYT, Forbes, etc.)
AEO Optimization: Person schema is essential for E-E-A-T (Experience, Expertise, Authority, Trust). AI engines look for author/teacher credentials when determining content quality.
<!-- Person Schema for Teacher --> <div itemscope itemtype="https://schema.org/Person"> <h2>Meet Your Teacher</h2> <img itemprop="image" src="vishen.jpg" alt="Vishen Lakhiani"> <h3 itemprop="name">Vishen Lakhiani</h3> <p itemprop="jobTitle">Founder of Mindvalley, Silva Instructor</p> <p itemprop="description">New York Times bestselling author...</p> <span itemprop="award">New York Times Bestselling Author</span> </div>
6

Social Proof & Results

Purpose: Provide third-party validation through testimonials, reviews, and measurable results.

Required Elements:

  • H2
    Section Headline
    "What Students Say" or "Real Results From Real Students"
  • DIV
    Aggregate Rating Display
    Show: Overall rating (4.8/5), total reviews count, star visualization
  • DIV
    Featured Testimonials (3-6)
    Each testimonial needs:
    - Quote text (focus on specific results)
    - Name and photo
    - Location and profession
    - Star rating (if applicable)
  • DIV
    Results/Statistics
    Quantifiable outcomes: "87% of students report improved focus within 2 weeks"
AEO Optimization: Review schema with aggregateRating makes the program eligible for rich snippets. AI engines cite review data when answering "Is [Program Name] worth it?" queries.
<!-- Review Schema --> <div itemscope itemtype="https://schema.org/Course"> <div itemprop="aggregateRating" itemscope itemtype="https://schema.org/AggregateRating"> <span itemprop="ratingValue">4.8</span> out of <span itemprop="bestRating">5</span> based on <span itemprop="reviewCount">25,163</span> reviews </div> <div itemprop="review" itemscope itemtype="https://schema.org/Review"> <div itemprop="author" itemscope itemtype="https://schema.org/Person"> <span itemprop="name">Lexi Lyons</span> </div> <div itemprop="reviewRating" itemscope itemtype="https://schema.org/Rating"> <meta itemprop="ratingValue" content="5"> </div> <p itemprop="reviewBody">Silva changed my life...</p> </div> </div>
7

Program Details & Logistics

Purpose: Answer all practical questions about how the program works, what's included, and what to expect.

Required Elements:

  • H2
    Section Headline
    "How [Program Name] Works" or "What's Included"
  • DIV
    Format & Delivery
    - How content is delivered (video, audio, text)
    - Daily time commitment
    - Self-paced vs. scheduled
    - Device compatibility
  • DIV
    What's Included Checklist
    - Number of lessons/modules
    - Workbooks/PDFs
    - Community access
    - Live calls/Q&As
    - Bonus materials
    - Lifetime access details
  • DIV
    "What Happens After You Order" Process
    Step-by-step: Order → Email → Login → Start Learning
AEO Optimization: This answers "How does [Program Name] work?", "Is [Program Name] self-paced?", "How long does [Program Name] take?" - all high-intent queries.
8

Pricing & Guarantee

Purpose: Present pricing clearly with value justification and risk reversal through guarantee.

Required Elements:

  • H2
    Section Headline
    "Start Your Transformation" or "Choose Your Plan"
  • DIV
    Pricing Card(s)
    For each option:
    - Plan name
    - Price (prominent)
    - What's included
    - CTA button
  • DIV
    Value Comparison (Optional)
    Compare to alternatives: "Traditional Silva seminars: $1,500+ | This program: $399/year"
  • DIV
    Money-Back Guarantee
    Prominent display of: Duration (15 days), process (one-click), no questions asked
  • DIV
    Trust Badges
    Security icons, payment logos, guarantee badge
AEO Optimization: Use Offer schema for pricing. This answers "How much does [Program Name] cost?" and "Is there a [Program Name] money-back guarantee?"
<!-- Offer Schema --> <div itemprop="offers" itemscope itemtype="https://schema.org/Offer"> <span itemprop="price">399</span> <meta itemprop="priceCurrency" content="USD"> <link itemprop="availability" href="https://schema.org/InStock"> <meta itemprop="priceValidUntil" content="2025-12-31"> </div>
9

AEO-Optimized FAQ Section

Purpose: Answer the questions people ACTUALLY search for (not just brand-centric FAQs). This is the PRIMARY AEO section.
Critical: The current Ultramind page has only 10 generic FAQs with no schema markup. This needs to expand to 25-30 search-intent questions with full FAQPage schema.

FAQ Categories Required:

  • 1
    General/Methodology Questions
    - What is [Program Name]?
    - How does [Methodology] work?
    - Is [Program Name] scientifically proven?
    - What's the difference between [Program] and [Alternative]?
  • 2
    Results & Outcomes Questions
    - What results can I expect from [Program Name]?
    - How long before I see results?
    - Does [Program Name] work for [specific use case]?
    - Can [Program Name] help with [specific problem]?
  • 3
    Practical/Logistics Questions
    - How long is [Program Name]?
    - How much time do I need per day?
    - Is [Program Name] self-paced?
    - Can I do [Program Name] on mobile?
  • 4
    Teacher/Expert Questions
    - Who teaches [Program Name]?
    - What are [Teacher's] qualifications?
    - Is [Teacher] a certified [credential]?
  • 5
    Comparison Questions
    - How is [Program Name] different from [Competitor]?
    - Is [Program Name] better than [Alternative method]?
    - [Program Name] vs [Similar Program]: Which is better?
  • 6
    Purchase/Access Questions
    - How much does [Program Name] cost?
    - Is there a money-back guarantee?
    - Can I cancel my subscription?
    - Do I get lifetime access?

FAQ Answer Formula

Each answer should follow this structure:

  1. Direct answer (first sentence - this gets pulled by AI)
  2. Supporting detail (2-3 sentences expanding on the answer)
  3. Proof/credibility (statistic, study, or testimonial reference)
<!-- FAQPage Schema (REQUIRED) --> <script type="application/ld+json"> { "@context": "https://schema.org", "@type": "FAQPage", "mainEntity": [ { "@type": "Question", "name": "What is the Silva Ultramind System?", "acceptedAnswer": { "@type": "Answer", "text": "The Silva Ultramind System is a 28-day mind empowerment program..." } }, { "@type": "Question", "name": "How long does Silva Ultramind take per day?", "acceptedAnswer": { "@type": "Answer", "text": "Each daily lesson takes 15-20 minutes to complete..." } } ] } </script>
10

Final CTA

Purpose: One last conversion opportunity after all information has been presented.

Required Elements:

  • H2
    Headline
    Summarize the transformation: "Start Your Mind Mastery Journey Today"
  • P
    Final Value Statement
    1-2 sentences reinforcing the core benefit and urgency
  • BTN
    Primary CTA Button
    Same as hero CTA for consistency
  • P
    Risk Reversal Reminder
    "15-day money-back guarantee. No questions asked."

Complete Schema Markup Requirements

Purpose: Structured data that enables rich snippets in Google and proper indexing by AI answer engines.

Required Schema Types:

Schema Type Purpose Key Properties
Course Primary page schema name, description, provider, instructor, duration, offers
Person Teacher/author credibility name, jobTitle, description, image, sameAs (social links)
FAQPage FAQ section mainEntity (array of Question/Answer pairs)
AggregateRating Review summary ratingValue, reviewCount, bestRating
Review Individual testimonials author, reviewBody, reviewRating
Offer Pricing information price, priceCurrency, availability
Organization Mindvalley brand name, url, logo, sameAs

Implementation Checklist

Before Launch Checklist

  • H1 contains primary keyword + benefit phrase
  • Meta description under 160 chars with keyword
  • Course schema implemented in JSON-LD
  • Person schema for teacher with credentials
  • FAQPage schema with 25+ questions
  • AggregateRating schema with review count
  • Offer schema with current pricing
  • All images have descriptive alt text
  • FAQ questions match actual search queries
  • FAQ answers start with direct response
  • Open Graph tags for social sharing
  • Mobile responsive verified
  • Page speed under 3 seconds
